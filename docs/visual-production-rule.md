# MIYU Academy — Visual Production Rule

Status: **APPROVED / LOCKED**

This rule is mandatory for all future visual work on MIYU Academy unless Olesia explicitly changes it.

## Source of truth

For each page and course screen, use only:

1. the already approved page skeleton / architecture;
2. the already approved prototype / layout direction;
3. the approved course content and fixed copy;
4. the already generated and explicitly approved visual assets;
5. explicit new visual requests from Olesia.

Do not invent a new page concept, new block structure, new copy, new story, new visual metaphor, or new layout direction on your own.

## Strict rule: no "creative reinterpretation"

Do **not**:
- replace the approved skeleton with a newly invented landing page;
- generate a new mockup when the task is to implement an existing approved prototype;
- add sections, headings, facts, labels or narrative that were not requested;
- redesign approved modules, certificate, hero, or page hierarchy;
- create decorative "AI fantasy" compositions that are not tied to an approved slot;
- spend image-generation credits on exploratory alternatives unless Olesia explicitly asks for alternatives;
- regenerate approved assets merely to "improve" them.

## Required workflow

Before creating any new visual asset:
1. identify the exact approved slot in the existing page skeleton;
2. state where the asset will be placed;
3. use the approved visual style;
4. generate only the asset needed for that slot;
5. do not alter the page architecture while generating the asset.

When Olesia asks to implement visuals:
- use the existing approved page code/skeleton;
- wire approved assets into their intended slots;
- add only restrained approved motion;
- preserve all fixed copy and interaction logic;
- do not change anything outside the requested scope.

## Credit discipline

Image generation is production, not brainstorming.

Do not generate speculative full-page mockups, duplicate variants, or "just in case" assets unless explicitly requested.

## Current Greek Mythology landing page

The current coded landing-page skeleton and approved prototype are the source of truth.

Future work must consist of:
- inserting the already approved hero and secondary visuals;
- adding the approved module-card images;
- preserving the existing section order and copy;
- applying the locked MIYU motion rule where appropriate;
- polishing spacing, cropping, responsiveness and transitions.

No alternative page concept should be introduced.
