## Решения, принятые с заказчиком
- Название: главное «Осетинский шёлковый платок», оригинал «Цыллæ хыз» — строкой над ним. EN-транслитерация: tsyllæ khyz.
- «Шаль» → «платок» в двух местах (гл. 01 и гл. 08), в обоих языках.
- Блок «Исторический архив» убран; «Из рук в руки» заменён на «Ремесло продолжает жить».
- Активности добровольные, без баллов/тестов/таймеров; анимацию можно выключить.
- **Никаких имён людей**: вместо них «одна из мастериц», «мастерицы рассказывают». Апи (божество) оставлено.
- **Картинки не обрезать**: сцены и галерея показываются целиком в своих пропорциях, без параллакса.
- **Галерея** (гл. 06): шёлк с коконов, плетение у окна, невеста, женщина у башен — вместо серии похожих невест.
- Надпись «Иллюстрация» на картинках убрана везде, без замены оговоркой (16.10.2026).
- Новые слова в тексте (подзаголовки, подписи к фактам) добавлять можно (16.10.2026).

## Текущая задача (16.10.2026)
Текст глав читается как сплошное полотно. Положение колонки ни при чём (PR #29 сдвинул её влево — заказчице не понравилось: «было полотно посередине, стало полотно сбоку»). Нужен ритм внутри глав: колонка снова по центру; подзаголовки каждые 3–4 абзаца (RU и EN); цифры и факты крупными акцентами; 2–3 выделенные цитаты на главу в разрыве текста; длинные абзацы разбить; иллюстрации чаще между абзацами, без обрезки. Сначала одна глава на согласование (скриншот), потом остальные.

## Сделано 16.10.2026 (PR «редакционная вёрстка»)
Колонка по центру не подошла («полоса в одну колонку»): главы свёрстаны журнально по сетке — секции по `### `, факты `[[fact: … | …]]` в боковом поле, картинки `[[pic:…]]` рядом с текстом, цитаты на всю ширину, остальной текст в две колонки. ## Технические заметки
- Английская страница на домене пережила несколько деплоев в старом виде (кэш CDN). Решено через `dynamic = "force-dynamic"` в page.tsx (PR #30). Пункта «Clear cache and deploy site» у заказчицы в интерфейсе Netlify нет.
- Локальная сборка без доступа к Google Fonts: `NEXT_FONT_GOOGLE_MOCKED_RESPONSES` с локальными woff2 из npm-пакетов @fontsource (forum, literata, manrope, inter, cormorant-garamond). Скриншоты — Playwright, Chromium лежит в /opt/pw-browsers.
- Порядок работы: ветка → PR → deploy preview (статус netlify/miyu-academy/deploy-preview) → squash-merge → проверка RU и EN на домене.
